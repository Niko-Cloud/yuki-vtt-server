# Fonts

The same two fonts the Yuki Char Maker website uses, kept in the app so it needs no
network to draw its window. Latin subsets, as served by Google Fonts.

- **Cinzel** (`cinzel.woff2`), by Natanael Gama. SIL Open Font License 1.1.
- **Alegreya** (`alegreya.woff2`), by Juan Pablo del Peral, Huerta Tipográfica. SIL Open
  Font License 1.1.
